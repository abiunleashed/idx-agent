# Film project (Quick mode)

the film (or says "continue", "devam"), load the cinecode skill (in Claude Code through the Skill tool, which also
starts its context guard; elsewhere read `/root/.claude/skills/cinecode/SKILL.md` once), read `STATE.md`, then follow
`/root/.claude/skills/cinecode/references/quick-mode.md`. Renders go through `tools/make.py`; the main chat builds and revises itself (quick-mode.md §6).
